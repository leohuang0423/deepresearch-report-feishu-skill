## 执行摘要

**推荐:分阶段混合策略——方向 A(AI agent 诊断优化服务)做现金引擎先行,方向 B(niche 实体)用 A 的现金流低风险验证,且 B 必须改形态(放弃"单件 1688 直发",改预售批量进口或数字/POD)。**

三个决定性事实:

1. **方向 A 到 $10k/月的数学最短**:市场审计行价 $5k-15k/项目,$10k/月 = 每月 2 单,启动成本≈0,且与你的技术背景完全匹配。$5k-25k"代客优化"价格带存在真实空白(工具商只卖软件,最近似服务商 Parlance Labs 起步价 $28.5 万)。(A2)
2. **方向 B 的原始构想已结构性失效**:2025 年美国取消 $800 小包免税 + 新店收款方对慢发货押 20-30% 保证金 60-90 天 + dropship 典型 25% 毛利下盈亏平衡 ROAS 4.0 vs 行业中位数 1.9-2.2——"先收钱再单件代发"在 2026 年三面受敌。(A3)
3. **但 B 的内核(痛点挖掘选品)依然成立**:实测挖出 2 个 7.5/10 的候选(售价/COGS 比 5-8 倍),改用"TikTok 自然流量 + 预售批量进口/数字产品"形态可行,只是到 $10k/月需 6-18 个月,不适合做首发引擎。(A3, A4)

**Shopify 的角色**:卖 B2B 服务无先例(标准打法是 landing page + 约电话),但 Shopify 完全可以充当"产品化服务"的官网+收银台(服务设为免发货商品),并在方向 B 启动时复用同一家店。这是兼顾你"要 Shopify 网站"诉求与行业现实的最优解。(A2, A5)

## 模块要点

### A1 · 痛点挖掘工具链(详见 raw/A1)

| 数据源 | 合规路径 | 成本 | 信噪比排名 |
|---|---|---|---|
| Amazon 1-3 星差评 | 公开网页,手动/轻量 | ~$0 | **#1 购买意愿**(已付费用户) |
| Reddit 垂直版块 | 官方 API 免费(100 QPM),2025/11 起新应用需预审批 2-4 周 | ~$0 | **#1 未满足缺口发现** |
| TikTok 评论 | 无合规 API(Research API 拒绝商用);事实通道为 Apify | $0.2-5/千条 | 量大噪声高 |
| Facebook 群组 | Groups API 已死(2024/4),好群都是私密群,Meta 最爱诉讼 | — | 风险/信号比最差,保持手动 |
| X | 2026 起按条计费 $0.005/读,免费档已取消 | 50K 读≈$250/月 | 最贵,只做精准查询 |

- 法律基线:hiQ v. LinkedIn + Meta v. Bright Data——登出状态抓公开数据可辩护,登录后抓取才是真实责任区。
- 前车之鉴:GummySearch(13.5 万用户)因拿不到 Reddit 商业授权 2025/11 关停。**挖掘做内部工具没问题,做对外产品有平台风险。**
- 结论:自建薄管道(Reddit 免费 + Apify TikTok + Amazon 差评手动 + F5Bot 免费监听)≈ $0-20/月 + LLM token。已实现于 `mining-pipeline/`。
- ⏰ 行动项:**现在就提交 Reddit API 应用审批**(2-4 周排队)。

### A2 · 方向 A:AI agent 诊断优化服务(详见 raw/A2)

- 需求证据(强):Gartner 预测 >40% agentic AI 项目 2027 年前被砍;Sinch 调研(2026/5,n=2527)74% 企业曾回滚客服 AI;LangChain 调研(n=1300)57% 已有 agent 上线、**质量是 #1 阻碍(32%)**——这正是你的 ICP。
- 竞争格局:LangSmith/Braintrust/Langfuse 等全部只卖工具($29-249/月),无人卖"代客优化";Humanloop 已被 Anthropic 收购关停;最近似服务商 Parlance Labs 最低 $28.5万/8 周,其 $3.5-5k 评测课程卖出 2000-4500 人——"修好我的 AI"需求远超高端供给。
- 定价锚:AI 审计项目 $5k-15k 固定价;独立顾问 $150-300/小时;LLM 专家 Upwork/Toptal 底价 $100-300/小时。
- 获客:暖网络 → LinkedIn 内容 + 触发式冷邮件(如:重新挂出 AI 岗位 60 天以上的公司)。无现成市场平台,得自己打。
- 风险:交付物易商品化、平台商可能内置自动优化、买方可能选择关掉 agent 而不是花钱修。
- **$10k/月数学:2 单 × $5k,或 3 单 × $3.5k。交付半自动化(评测→诊断→改进包),每单边际成本≈API token $100-300 + 你 2-3 天时间。**

### A3 · 方向 B:niche 实体电商(详见 raw/A3)

- 广告现实(2025-26):Meta 中位 CPM $13.5、电商 CPA $38、ROAS 1.93;TikTok CPA $32.7、ROAS 2.21。25% 毛利的 dropship 盈亏平衡 ROAS 是 4.0——**中位数广告主在结构上亏钱**。
- 行业基率:幸存者净利 10-20%,80-90% 店铺一年内死亡;$10k/月利润 ≈ $50-70k/月营收,现实时间线 6-18 个月 + 五位数累计投入。
- 预售+中国直发的三道墙:① FTC 邮购规则(必须标注并兑现发货日期,违者 $4 万+/次);② Shopify Payments/Stripe/PayPal 明确盯防 dropshipping 与长发货周期,新店预期 20-30% 滚动保证金押 60-90 天——**"用客户的钱去进货"的循环被掐断**;③ 小包免税已死(2025/5 对华、2025/8 全球),按值征税,单件直发成本崩坏(中国邮政小包量跌 ~80%)。
- 可行变体:**数字产品**(毛利 70-95%,盈亏平衡 ROAS ~1.1,唯一中位广告主能打正的形态)> **美国 POD**(毛利 20-50%,3-7 天本土发货,零关税)> **微批量进口**(预售一批 → 1688 代理集货(~5% 费)→ 整批空运清关 → 美国 3PL 发货——Temu/Shein 玩法的缩微版)。
- 框定预售可行:标注醒目发货日期时客户可接受 12-41 天等待;不框定则 35% 的人在一次延迟后永久流失。

### A5 · Shopify 实施事实(详见 raw/A5)

- 套餐:Basic $39/月(年付 $29);不用 Shopify Payments 每单加收 0.2-2%。
- **大陆主体不支持 Shopify Payments/Stripe**。路径:① 美国 LLC(Stripe Atlas $500 一次性 + 年合规,3 年总成本 $3.1-4.6k,注意 Form 5472 漏报罚 $2.5 万);② PayPal 中国直收(~4.4%+跨境费,无需美国主体,起步够用);③ 香港/新加坡主体可直接用。
- 卖服务/数字品:原生支持——商品不勾"实体",首方 Digital Downloads 应用免费。
- 主题:2025/5 起默认主题为 **Horizon**(嵌套 Theme Blocks);Dawn/OS 2.0 仍完全支持,CLI `theme dev/push/check` 工具链不变。**建站包按 Horizon 或 Dawn 均可,选 Dawn(文档最丰、定制生态最熟)。**
- 履约:CJdropshipping 是唯一原生支持 1688 寻源的主流应用(免费寻源工单,24-48h 报价,自动履约);DSers 仅 AliExpress。
- TikTok Shop 美国站实际对非美居民关闭(要求美籍法人代表+W-9);**TikTok 自然流量 → 自有 Shopify 店无门槛**——这是低预算冷启动主通道。
- 基准:转化率均值 1.4-1.8%,AOV $80-120;邮件弹窗收集 2-5%(游戏化 6-12%);Klaviyo 免费档 250 联系人很快用完,预算 $20/月。

## 方向对比(调研后)

| 维度 | A:agent 诊断优化服务 | B:niche 实体(修正形态) |
|---|---|---|
| 到 $10k/月路径 | 2 单 × $5k/月,**1-3 个月可达** | $50-70k 营收 × 15-20% 净利,**6-18 个月** |
| 启动成本 | ≈$0(API token + 域名) | $2-5k(样品+批量首单+广告测试) |
| 失败基率 | 低(按单收费,无库存) | 高(80-90% 店铺年内死亡) |
| 自动化度 | 交付 60-80% 可自动化;**销售难自动化** | 履约可 90% 自动化;**素材/选品需持续迭代** |
| 与你能力契合 | 极高(你已有 agent 评测方法论资产) | 中(需补投放与供应链) |
| 结构性风险 | 商品化、平台内置化 | 关税、收款保证金、广告通胀 |
| Shopify 适配 | 可用(服务=免发货商品),非行业惯例 | 原生场景 |

## 推荐方案:三阶段

**Phase 1(第 0-2 月)· A 方向冷启动 = 现金引擎**
- 产品化定价:`Agent Audit Sprint` $4,500(客户给接口+1000 条对话 → 10 个工作日交付:失败模式图谱 + 可直接落地的 prompt/skill/知识库改进包 + 前后对比评测报告);引流款 `Mini Diagnostic` $499(500 条对话自动诊断报告,自助下单)。
- 渠道:LinkedIn 内容(每周 2 篇真实诊断案例拆解)+ 触发式冷邮件(挂 AI 岗 60 天+、用 Intercom/Voiceflow 等的公司)+ 暖网络。
- Shopify 店上线:服务即商品(免发货),$499 引流款可直接 add-to-cart,$4.5k 主力款挂"预约诊断电话"。
- 里程碑:第 2 个月末拿到 2 个付费客户 → 验证通过。

**Phase 2(第 1-3 月,并行)· 周更挖掘 + B 方向轻验证**
- 每周跑一次 `mining-pipeline/`,维护机会榜。
- 选 1 个候选(默认 #1 匹克球拍隔热套:COGS $4、轻、不易碎、无认证、人群狂热)做**预售页**挂到同一家 Shopify 店:1688 打样($50-100)→ 真人短视频投 TikTok 自然流 → 预售页明示发货日期(FTC 合规)→ 30 单内用 CJdropshipping/代理集货履约。
- 通过标准:自然流量转化率 ≥2% 或 100 个邮件等候名单 → 才投第一笔广告。

**Phase 3(第 3-6 月)· 加倍赢家**
- A 跑通:涨价至 $6-8k、加 $1.5k/月持续监控订阅(真正的"自动化赚钱"部分)。
- B 跑通:批量进口 + 美国 3PL,扩 SKU(同人群第二痛点),TikTok 联盟(纳米创作者寄样,ROI 约为投流 2 倍)。
- 哪条先到 $10k/月就把另一条降级为副线。

## 单位经济模型(到 $10k/月)

**A 线(主推):**
```
2 × Agent Audit Sprint $4,500        = $9,000
4 × Mini Diagnostic $499             = $2,000
─ API/token 成本 (~$300×2 + $30×4)   = -$720
─ 工具/订阅                          = -$200
≈ 月净 $10,080;需你投入 ~6-8 天/月交付 + 持续内容获客
关键假设(待验证):50 封定向触达 → 5 通电话 → 1-2 单
```

**B 线(修正形态,匹克球拍隔热套):**
```
售价 $27.99(运费另收或 $34.99 包邮),捆绑双只装 $49.99 拉 AOV
COGS $4.5 + 批量头程+3PL 履约 ~$7 → 单件贡献 ~$16(57%)
$10k/月利润 ≈ 仍需 ~650 件/月 → 纯靠它到 $10k 不现实(CPA $33-38 下广告打不正)
定位:自然流量驱动的 $2-4k/月副线 + 验证方法论,扩 SKU 后再上量
```

## 主要风险与对策

| 风险 | 对策 |
