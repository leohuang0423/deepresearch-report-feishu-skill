> 与本报告口径一致的结论。评分为 1–5 分（5 = 最佳）。"实测来源"列标明该分数在本仓库里是**真跑出来的**
> 还是**基于公开资料/构造性事实**的判断。

## B. 两套用途权重（同一组分数，权重不同 → 结论会翻转）

### B1. 带货/转化型信息流广告（performance ad）—— 重信息准确、可控、成本、规模

| 路线 | 加权得分（/5） |
| --- | ---: |

> 结论：performance 广告里，"信息逐字准确 + 可控 + 可批量 + 低边际成本"压倒一切，**代码路线明显占优**。

### B2. 品牌故事/实拍质感 TVC —— 重真实感、情绪、镜头语言、原生音画

权重：1=6, 2=10, 3=8, 4=4, 5=4, 6=6, 7=8, 8=30, 9=12, 10=12（合计 100）

| 路线 | 加权得分（/5） |
| --- | ---: |
| HTML/代码 | 3.68 |
| **图生视频 AI** | **3.76** |

> 结论：要"像真的拍出来"的情绪片/实拍质感，**图生视频反超**（且差距会随真实感权重继续拉大）。

## D. 评分方法学与诚实声明

- HTML/代码一侧的第 1/3/4/6/7 维与 C 表"本仓库实测"列，来自本仓库**真实渲染**的成片
  （`output/ecommerce-ad-1080x1920.mp4`），可逐帧核验。
- HTML 一侧第 8 维（真实感）为**构造性事实**：纯 CSS/DOM 不产生实拍质感，这是范式上限，不需实验即可判定。
- 图生视频一侧全部分数为**基于 2026 年公开资料 + 范式特性**的判断（来源见主报告参考文献），
  **未在本容器内实跑**（无 API 密钥、出网白名单限制）。要把它变成"完全实测对比"，
  按 `assets/shared-brief.md` 第 5 节跑一遍 B 组、回填 C 表即可。
- 权重可按你的真实投放结构调整 B1/B2；本卡的价值是**口径统一**，不是某个绝对分数。
