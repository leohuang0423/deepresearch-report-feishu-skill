⑤ 推荐：生产级混合工作流

  1. AI 生成"难拍的料"：实拍质感 b-roll、模特上脸、质地特写、氛围镜头。
  2. coding agent 当合成 + 信息层：用 HTML/CSS/JS（或 Remotion）把片段 + 真实产品图 + 逐字准确的价格/卖点/CTA/字幕合成成片——信息层绝不交给生成模型写字。
  3. 数据驱动批量：价格/赠品/语言/话术抽成参数表，一套模板批量出千条变体。
  4. 确定性收尾：合成与字幕在代码侧完成 → 可复现、可审计、投放零事故。

一句话：让 AI 负责「像真的」，让代码负责「准且多」。
