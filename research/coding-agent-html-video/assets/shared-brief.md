# 共享创意 Brief（两条路线的同一输入）

> 这份 brief 是本次对比测试的**唯一受控变量入口**：HTML/代码路线和图生视频路线都必须只拿这份 brief 去产出，
> 才能保证对比是"同题作答"。把下方"给图生视频 agent 的 prompt 包"整段贴给 Sora / Veo / Kling / Runway / 即梦
> 等工具或其 agent 工作流，即可复现 B 组。

## 1. 商品与目标

- 商品：AURA 鲜橙 VC 精华液（虚构品牌，用于测试，不指向任何真实产品）
- 品类：美妆护肤 / 精华
- 投放场景：抖音 / 视频号 / TikTok 信息流 + 直播间贴片
- 目标：performance ad（带货转化），非纯品牌片
- 画幅 / 时长 / 帧率：竖屏 9:16，1080×1920，15 秒，30fps
- 语言：简体中文为主

## 2. 必须出现且**逐字准确**的信息（硬约束）

这些是电商投放的"事实层"，**一个字都不能错、不能糊**：

| 字段 | 内容 |
| --- | --- |
| 品牌名 | AURA |
| 品名 | AURA 鲜橙 VC 精华 |
| 核心成分 | 20% 高浓度 VC、玻尿酸、烟酰胺 |
| 功效数据 | 肤色提亮 +30%（2 周）、87% 用户感受细纹变淡、8 小时长效锁水 |
| 口碑 | 4.9 分 · 12,000+ 真实好评 |
| 价格 | 原价 ¥199 → 直播价 ¥149 |
| 促销机制 | 前 500 件加赠 30ml 同款小样 · 顺丰包邮 |
| CTA | 立即抢购 |

## 3. 分镜脚本（15s · 6 段）

1. 0.0–2.8s 钩子：黑紫极光背景，品牌 AURA 字母逐个弹入，slogan「晨光般的透亮肌」。
2. 2.8–4.7s 痛点：暗沉 / 粗糙 / 没气色 三连击划掉，转「现在，肌肤有了新答案」。
3. 4.7–8.5s 产品主秀：精华瓶上浮微浮动，光晕旋转，三枚成分标签弹出，主标题「一滴唤醒透亮好气色」。
4. 8.5–11.1s 功效实证：标题「实测有效」，三张数据卡数字滚动（+30% / 87% / 8h）。
5. 11.1–12.8s 口碑：五星点亮，4.9 分，12,000+ 好评，真实评价气泡。
6. 12.8–15.0s 促销 + CTA：¥199 划掉 → ¥149 弹出，赠品/包邮，「立即抢购 →」按钮脉冲。

## 4. 视觉调性

- 色板：深莓紫/酒红背景 + 暖橙/金 (#ffb24d / #f6d68a / #ff7e5f) 高光，奶油白文字。
- 质感：高级、通透、有光泽；颗粒感 + 暗角；柔和粒子上浮。
- 动效：缓出（ease-out）为主，关键信息用 ease-out-back 弹入；信息密度高但不杂乱。

## 5. 给图生视频 agent 的 prompt 包（B 组直接复制）

```
角色：你是电商短视频投放的 AI 视频导演 agent。
任务：用图生视频 / 文生视频工具产出一支 9:16、1080×1920、15 秒、30fps 的美妆精华带货短视频。
输入素材：产品图（若有则用 image-to-video 保真；若无则文生视频）。
严格约束：
1) 以下文字必须在画面中逐字清晰、全程不糊、不变形：
   品牌 AURA；品名「AURA 鲜橙 VC 精华」；「20% 高浓度 VC / 玻尿酸 / 烟酰胺」；
   「肤色提亮 +30%」「87% 用户感受细纹变淡」「8 小时长效锁水」；
   「4.9 分 · 12,000+ 真实好评」；「原价 ¥199 直播价 ¥149」；
   「前 500 件加赠 30ml 同款小样 · 顺丰包邮」；「立即抢购」。
2) 产品瓶身、标签、颜色全程一致，不得 morph / 漂移 / 多生一个瓶子。
3) 分镜与时间轴严格按第 3 节 6 段执行，单段误差 < 0.3s。
4) 色板与调性按第 4 节。
请输出：成片 MP4 + 你为达成上述约束所做的 prompt / reroll / 后期补字 记录。
```
